# dsh-usage

在 DSH 输入框下方原有轮数、Token 和上下文统计之后**追加**账户用量；不替换任何原有统计，不修改 GPT 模型选择；只有用户在账号预览中点击对勾，才会正式切换 Codex 活动账号。

- **Codex**：复用已安装的 [dsh-codex-subscription](https://github.com/WSL043/dsh-codex-subscription) 的 `status` 和 `usage` 活动账号接口及其缓存。**常驻栏只显示当前活动账号**的剩余额度百分比和重置倒计时；支持两个及更多账号。在多账号详情展开时，通过原插件的只读 `usage/accounts` 接口读取各账号额度以供循环预览，不同时展示，也不自动切换账号。按所选模型匹配独立额度池（包括 Spark）。窗口时长以服务端为准，典型窗口标为 `5h`、`7day`。
- **DeepSeek 账户**：读取 DSH 内置 `remote.account.getBalance()`，按币种合计充值余额和赠送余额，不保存凭据。
- API Key 路由 `deepseek-official` 不消耗已登录 DSH 账户的钱包，因此不会错误地显示该账户余额；其他暂不支持的提供商不显示。
- 每 60 秒读取，切换提供商即切换内容；页面隐藏时暂停，回到前台刷新。模型变化直接重选相应额度池，无需等待下一次读取。
- Codex 账号切换使用原插件的通知立即失效旧值；读取前后核对账号列表，防止串号。读取失败、未登录和缺少额度信息均明确提示，不伪造百分比。到达重置时间仅显示“等待重置”，直到服务端返回新值。
- 使用 `conversation.composer.dock` 的独立 `dsh-usage` 条目（order 20），继承宿主主题和字体，常驻栏保持单行，占用不超过底栏宽度的 40%；窄窗口或展开侧栏时收缩并显示省略号，不撑高底栏，完整额度和倒计时可点击查看。原插件自身输入框额度指示器保持原样，可在其设置里自行隐藏。

示例（数值仅为格式说明）：

```text
[原有会话统计]  5h 83% ↻ 4h59m 7day 61% ↻ 6d9h
（切换活动账号后）
[原有会话统计]  5h 96% ↻ 3h12m 7day 85% ↻ 5d2h
[原有会话统计]  ¥68.28
```

Codex 的账号标签、邮箱及重置时间的当地时间放在点击详情中；常驻栏只显示用量和倒计时，不显示 `codex Account 1` 等前缀。

## 点击查看详情

点击上下文使用率后面的金额/额度，弹出随内容自适应高度的详情卡片；点击空白处、再次点击触发按钮、关闭按钮或按 Escape 关闭。弹层优先向上打开，自动避让窗口边缘，支持键盘焦点和窗口缩放，卸载时清理监听。自 0.3.2 起通过宿主 React DOM Portal 将详情挂载到 `document.body`，避免 DSH `0.2.2-rc.1` 输入框容器对固定弹层的包含/裁剪限制。

- 左上角为提供商名称（当前数据源为 **Codex** / **DeepSeek**），另列当前模型。名称逻辑可沿用模型目录名称，例如未来接入 Capinfo 时无需改写标题；**本版不新增 Capinfo 取数接口**。
- Codex：默认当前账号，可用标题旁的切换按钮预览其他账号，**5 小时限额**、**7 天限额**分块纵向展示，列出剩余百分比、以“x 天 x 小时 x 分”展示的刷新倒计时及完整重置日期/时间；不显示已用百分比。
- DeepSeek：展示充值余额、赠金余额和合计；常驻栏仍只显示 `¥67.21` 这样的两位小数金额。
- 展示数据更新时间；Codex 使用原接口的 `fetchedAt`，不是将本地轮询时间伪装成数据源更新时间。重置时间与更新时间分别标注，不混淆。日期跟随浏览器时区，界面文字跟随 DSH 语言（含中文）。

## Codex 多账号预览与启用

当前模型提供商是 Codex 且已登录多个账号时，详情标题 `Codex` 后面显示切换图标：

1. 点击图标循环预览各账号用量，预览标为“预览账号”；常驻栏仍显示正在使用的账号。
2. 仅预览非活动账号时显示对勾。点击对勾才调用原插件的 `account/select` Host 操作，不改写凭据、不调用模型选择接口，GPT 型号和推理档位保持不变。
3. **活动账号属于全局设置，对所有 Codex 会话生效**，与原插件设置里的切换操作完全相同。账号凭据/计费身份的启用只接受用户明确点击对勾确认，不提供让模型自行启用账号的工具。
4. 启用前核对账号仍存在、活动账号与预览时一致；若已在其他位置切换则拒绝陈旧确认（此检查不是跨客户端的原子锁）。提交后重新查询状态确认，并通知原插件刷新额度；网络错误也重新读取，避免假定服务端未生效。
5. 提交中禁用重复操作；失败在弹层中提示，不悄悄切回旧账号。关闭详情丢弃预览选择，卸载取消未完成请求。单账号或 DeepSeek 不显示这组按钮。
6. 多账号预览请求只在 Codex 多账号详情打开时保留，关闭后停止轮询；对某账号额度读取失败会明确提示，不会借用其他账号额度填充。

## 安装

先克隆公开仓库：

```sh
git clone https://github.com/0xlic/dsh-usage.git
cd dsh-usage
npm run check
```

然后在 DSH 插件管理器中添加克隆目录的**绝对路径**，或由 Agent 调用 `plugin_manager install_bundle`。没有第三方依赖或安装脚本，无需启动其他服务器。安装结果若要求重启，按 DSH 提示重启。本项目目前通过 GitHub 分发，尚未发布到 npm。

当前实现依据 DSH `0.2.1-rc.5` 内置接口及 Codex Subscription `3.2.5`，接口变化可能需要适配。余额请求的 UI 版本字段与此 DSH 版本匹配。

## 开发

```sh
npm run check
```

直接编辑 `client.source.js` / `logic.js`，然后 `npm run build` 生成 `client.js`。仅使用宿主 React，不打包另一份 React，也不导入 Harness Client 组件包。所有订阅、定时器、请求及 slot 注册随卸载清理。安装后的代码更新以插件管理器的重启提示为准，不能假定只改磁盘文件就会热更新。

## 验证

自动化测试覆盖提供商路由、模型额度池选择、双账号 ID 关联、窗口/倒计时、精确余额求和、共享请求去重、晚到请求丢弃、失败状态和卸载清理。安装后需检查当前 GUI 中 `conversation.composer.dock` 是否包含 `dsh-usage`，再人工切换 Codex / DeepSeek 账户模型确认实际数值和布局。没有浏览器控制时不能将 slot 注册视为视觉验证通过。
